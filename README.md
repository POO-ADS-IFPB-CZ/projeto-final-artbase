## ✅ Pré-requisitos

- Java JDK 17+ (ou versão usada na disciplina)
- IDE Java (IntelliJ, Eclipse ou VS Code)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/POO-ADS-IFPB-CZ/projeto-final-artbase.git
```

2. Acesse a pasta do projeto:

```bash
cd projeto-final-artbase
```

3. Compile e execute pela sua IDE ou via terminal (dependendo da estrutura do projeto).
